## 为什么做这个网站

这是我个人网站的第一篇文章。搭建这个网站的目的很简单：想要一个属于自己的角落，记录学习笔记、项目经历和一些想法。

## 这个网站是怎么搭的

- **框架**：Next.js 16（App Router + 静态导出）
- **样式**：Tailwind CSS v4
- **部署**：GitHub Pages + GitHub Actions 自动部署
- **博客**：Markdown 文件 + gray-matter / remark 渲染

## 接下来的计划

- 把这里的占位内容换成真实的自我介绍
- 持续写博客，记录学习和项目进展
- 逐步加入深色模式、RSS 等功能

感谢阅读，欢迎常来逛逛！
